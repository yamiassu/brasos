# Welcome to BrasOS

BrasOS is a Linux-based operating system whose whole interface is built with web technology: React and TypeScript. Apps are **PWAs** (Progressive Web Apps), every app runs isolated from the others, and anyone can build an app or change how the interface looks.

> **Status: early foundation. Not for real use.** The *dev* image is insecure on purpose (a default password, passwordless root, an AI agent with full privilege). The *hardened* image is a work in progress: it has not been audited or certified. See [Security](08-security.md).

## What you can do

- On the first start, a short **setup** asks who uses the computer and how it should look (see [Using BrasOS](02-using-brasos.md)).
- Open apps from the **desktop icons**, the **taskbar** along the bottom, or the **search box** (also **Ctrl+K**).
- Browse and edit your files in **Files**.
- Load websites in **Browser**, including sites written in TypeScript, and **install** sites that are PWAs as apps.
- Read these guides in **Docs**.
- Let an AI agent drive the whole system through typed tools: see [Agents](07-agents.md).
